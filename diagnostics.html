탐색 속도 비교

같은 모델·기보·탐색량으로 기존 경로와 개선 경로를 비교합니다. 계산과 결과 파일 생성은 이 기기에서 이루어집니다.

측정 설정

기존 WASM 경로는 항상 함께 측정합니다. 탐색량은 4~16,384회 정수입니다. 초기화·워밍업은 착수 통계에서 제외합니다.

고정 국면
기보 목록을 불러오는 중…

각 반복에서 캐시를 비운 탐색(cold)을 실행한 직후, 같은 국면을 캐시를 유지한 채 한 번 더 탐색(warm)합니다. 두 결과는 따로 비교합니다. 기본 전체 측정은 수 분 이상 걸릴 수 있습니다. 이 탭을 앞에 두고 다른 무거운 작업을 멈추면 비교하기 좋습니다.

진행 상태

대기 중 · 시작을 누르면 실행 엔진을 불러옵니다.

아직 측정 결과가 없습니다.

이 판의 표시 시간은 진단 요청부터 결과판 표시까지입니다. 실제 대국 화면의 사람 클릭부터 AI 착수까지의 시간과 구분해 기록합니다.

착수 시간

      
중앙값과 p95는 초 단위입니다. 반복 수가 적을 때 p95는 안정적인 꼬리 지연 추정치가 아닙니다. 같은 모델·완료 탐색 수·결과판·탐색 통계가 일치하는 반복끼리 속도 차이를 계산합니다. GPU 요청이 WASM으로 복구된 경우 GPU 실측으로 표시하지 않습니다.

AI 시간에는 탐색 및 결과 snapshot이 포함됩니다. 기보 준비·사람 수 처리 등 별도 측정 구간과 중첩된 세부 타이머는 JSON에 보존하며, 이들을 더해 전체 시간으로 표시하지 않습니다. 실제 완료 탐색 수·신경망 평가 수와 요청 예산은 별도 카운터로 기록합니다.

결과를 읽는 방법

      
  1. 기본 설정으로 전후 비교 시작을 누릅니다. GPU를 사용할 수 없어도 WASM 결과와 복구 사유가 남습니다.
  2. cold는 신경망·규칙 캐시를 비운 결과, warm은 바로 앞 동일 국면의 캐시를 남긴 결과입니다. 반복 캐시 효과를 일반적인 가속으로 해석하지 마세요.
  3. 실제 어댑터 정보·provider 증거·모델 해시·원시 표본·오차·세부 타이머는 JSON에서 확인합니다. 어댑터 정보가 없으면 RTX 사용 여부는 확인되지 않은 것입니다.
  4. 중단하면 실행 중 Worker를 종료합니다. 이미 모은 표본은 내려받을 수 있습니다. 다시 시작하면 새 Worker에서 재측정합니다.

      
모든 실행 경로를 먼저 준비하고, 같은 국면·탐색량을 한 경로씩 번갈아 측정합니다. 매 반복마다 경로 순서를 순환해 기본 3회에서 순서를 균형 있게 배치합니다. 각 경로의 cold 직후 warm을 실행하며 동시 탐색은 하지 않습니다. 여러 세션을 유지하므로 일반 대국보다 메모리를 더 사용합니다. 발열·전원·백그라운드 영향은 여전히 남습니다. 이 도구는 대국 기본 설정을 자동으로 바꾸지 않습니다.
